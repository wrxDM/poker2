**Board（公共牌）：** A♠ T♠ 8♥ 5♥ 2♥


| 玩家    | 手牌    | 下注金额 | Folded | All-in | 最终牌型 |
| ----- | ----- | ---- | ------ | ------ | ---- |
| Alice | A♠ K♠ | 20   | 是      | 否      | —    |
| Bob   | A♥ K♥ | 50   | 否      | 否      | 同花   |
| Carol | 2♥ 3♥ | 50   | 否      | 否      | 高牌   |



| 总底池 | 分配后总筹码 | Alice | Bob     | Carol |
| --- | ------ | ----- | ------- | ----- |
| 120 | 120    | 0     | **120** | 0     |
